# Chaoxing Course QA

用于已获授权的学习通测试课程，模拟普通学生从网页正常播放视频，并验证章节衔接是否正常。
不会自动答题，仅仅刷视频

## 安全边界

- 仅操作当前由用户手动启动的 Chrome 或者 edge 标签页。
- 使用课程播放器的默认正常速度，不跳转视频进度、不静音、不伪造学习时长。
- 不调用学习通私有接口，不读取或导出 Cookie、登录令牌和密码。
- 不填写或提交测验、作业、考试、签到和讨论。
- 遇到验证码、人脸识别、身份认证或安全验证时暂停，等待人工处理。
- “下一节/下一章”只有在对应页面区域内存在唯一、安全且文本完全匹配的按钮时才会点击。

在本目录运行：


## Chrome 测试安装

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录 `D:\other\ai\chaoxing-course-qa`。
5. 刷新已经打开的学习通页面。
6. 页面右下角出现“课程 QA”面板后，由用户点击“开始”。

安装扩展会改变浏览器状态，实际安装前应由用户现场确认。

## 当前版本

当前版本为 0.11.1。扩展会根据页面文字重新判断当前处于“学习目标”“视频”还是“章节测验”，不依赖固定的节数或章数。学习目标文字可以位于课程 iframe，而页面底部的导航可以位于顶层页面：识别文字的 frame 会向后台登记一次性前进任务，再由能看见导航的 frame 优先点击学习通实际使用的可见 `#prevNextFocusNext`。按钮也可以是普通链接、按钮或由 `div/span` 实现的可点击控件。对于学习通保留在页面中的隐藏式 `a.nextChapter`，只有当它带有站点自身的 `PCount.next(...)` 处理器且当前流程明确需要前进时才会作为后备入口；若页面存在多个布局副本，会用当前页 `chapterId` 筛选，并且只接受动作完全相同的重复控件。视频使用课程播放器的默认正常速度，自然结束后进入下一页。旧视频 iframe 延迟发来的播放消息不会再覆盖新页面状态。

后台每 30 秒检查一次运行状态。自动视频巡检连续 2 分钟既没有页面流程进展、也没有实际视频播放时间前进时，只产生一次系统提示“自动播放视频错误”；任何进展都会重新开始计时并解除本轮超时锁。浏览器或视频全屏期间暂不显示，退出全屏后立即补发。

“跳过章节测验，稍后完成”开启时，扩展识别章节测验后点击页面底部导航，然后进入独立的“等待确认提示”阶段；若随后出现“当前章节还有任务点未完成，是否去完成？”提示，只点击该提示框内部的“下一节”。导航查找会同时在顶层页面和课程 iframe 中执行，但后台只允许一个页面成功领取本次点击。确认提示支持学习通实际使用的 `.maskDiv/#workpop/#hintPop` 结构；当页面把原生 `.nextChapter` 按钮作为隐藏预置控件时，也只会在流程明确需要前进时触发该控件。扩展不会选择答案或提交测验。下一页若仍是学习目标，会再按上述规则进入视频。关闭该选项时，扩展会等待测验出现“已通过”“已提交”“提交成功”“查看答案”“重新作答”或“重做”等结果后再继续。

“开始”按钮在启动成功后显示“进行中...”并禁用，点击“停止”后恢复。启动后会先查找并点击唯一可见的播放器中央播放按钮，再等待 HTML5 视频初始化；如果按钮点击后 15 秒仍未出现可播放视频，则触发系统错误通知。

播放或导航发生错误时，仅显示标题为“自动播放视频错误”的系统通知。网页或浏览器处于全屏状态时，错误会先在本地排队，退出全屏后立即通知；不会显示页面错误框、扩展角标或声音提示。
